プライバシーポリシー

制定日: 2026年9月29日

このページは、個人用のタスク管理アプリ TaskSkill（Mac・iPhone・iPad 版。以下「本アプリ」）が、利用者の情報をどのように扱うかを定めるものです。本アプリは開発者本人が個人で使うためのもので、一般には配布していません。

1. 本アプリが扱う情報と、その使い道

本アプリは、利用者が許可した場合に限り、利用者本人の Google アカウントの次のデータを使います。

  • Google カレンダーの予定（スコープ: calendar.events）: 利用者が本アプリで日に置いたタスクを、専用カレンダー「TaskSkill」に予定として作成・更新・削除するため。また、利用者が選んだカレンダーの予定を読み込み、空いている時間を本アプリの画面に表示するため。
  • Google カレンダーの一覧（スコープ: calendar.calendarlist.readonly）: 読み込むカレンダーと書き出し先を、利用者が選べるようにするため。
  • Google ドライブの、本アプリ専用の見えない場所（スコープ: drive.appdata）: 利用者のタスク・前提関係・予定・画面上の配置を、利用者の端末どうしで同期するためのファイルを保存し、読み込むため。本アプリは、利用者のドライブにあるほかのファイルを見ることはできません。

2. 保存する場所

  • 本アプリのデータは、利用者の端末の中と、利用者本人の Google アカウント（上記のカレンダーとドライブ）にだけ保存します。
  • 開発者のサーバーは存在せず、利用者のデータを開発者に送ることはありません。
  • Google へのログインで受け取る認証情報（トークン）は、端末の安全な保管場所（macOS・iOS のキーチェーン）に保存します。

3. 第三者への提供

利用者の情報を第三者に提供・販売することはありません。広告にも使いません。

4. Google API サービスのユーザーデータに関するポリシーの遵守

本アプリが Google API から受け取った情報の使用と、他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

5. アクセスの取り消しと削除

  • 本アプリの設定の「接続を切る」で、端末に保存したトークンを削除できます。
  • Google アカウントの「サードパーティ製のアプリとサービス」から、本アプリへのアクセスをいつでも取り消せます。
  • 本アプリを削除すると、端末の中のデータも削除されます。ドライブの専用の場所にあるファイルは、上記の方法でアクセスを取り消すと削除されることがあります。

6. このポリシーの変更

内容を変える場合は、このページで告知します。
